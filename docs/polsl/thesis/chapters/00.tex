\subsubsection*{Streszczenie}

Praca opisuje proces projektowania i~implementacji układu aktywnej redukcji
hałasu na bazie wbudowanego systemu Linux z~rozszerzeniami czasu rzeczywistego w
oparciu o samodzielnie skonstruowaną elektronikę, komunikującą się
z~zainstalowanym na platformie obliczeniowej systemem operacyjnym i~aplikacją
działającą w~trybie użytkownika. W~treści szczegółowo wyjaśnione zostały zasady
działania systemów aktywnej redukcji hałasu, przedstawiony został przebieg
realizacji części sprzętowej i~programowej układu wraz z~weryfikacją ich
działania. Na skonstruowanym układzie wykonany został zestaw badań sprawdzający
wpływ konfiguracji systemu na~uzyskany poziom tłumienia oraz~przedstawione
zostały obserwacje dotyczące możliwych usprawnień.

\subsubsection*{Abstract} 
\begin{otherlanguage}{british}

The thesis describes the design and implementation process of~active noise
control system based on~embedded Linux with real-time extensions using
self-constructed electronic circuit communicating with operating system
installed on chosen computing platform and user-space application. The content
explains in~detail the principles of~active noise control systems, the course of
hardware and software parts implementation was presented along with
verificiation of their operation. On the~constructed system a~set of~tests was
performed to check the influence of system configuration on the obtained
attenuation level. Finally, observations regarding possible improvements have
been made and presented. 

\end{otherlanguage}
