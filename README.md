# Active noise reduction system under the supervision of the Linux kernel with real-time extensions
The repository contains hardware, firmware and system software for master thesis project.

# Project structure
Project consists of a following modules:
- **base** - docker related stuff
- **hardware** - KiCAD electronics and PCB design
- **software** - application software environment
- **system** - system software, GNU/Linux OS building tools
- **docs** - school presentations and thesis draft
